## Cómo se refleja en GitHub

- **Issues:** cada HU-XX tiene un issue (plantilla "Historia de usuario") con
  el campo *Assignees* igual al integrante de esta tabla.
- **Project:** el campo personalizado `Owner` de cada tarjeta coincide con el
  *Assignee* del issue.
- **Milestones:** un milestone por módulo (Autenticación, Ficha del postulante,
  Anuncios y empresas, Postulantes + WhatsApp) para ver el avance de cada
  persona de un vistazo.
